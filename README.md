# App Design Assets Starter Pack

Starter SVG assets for the telecom dealer app.

## Folders
- assets/icons
- assets/illustrations
- assets/backgrounds
- assets/themes

## Theme-aware SVG convention
Most SVGs use these CSS variables with fallbacks:
- --primary
- --primary-soft
- --accent
- --text
- --muted
- --surface
- --success

You can replace them in React Native or web pipelines, or use the fallback colors directly.
