# Theme Assets

Use these rules for theme-aware visuals:

- Keep icon/illustration geometry identical across themes.
- Change accent, secondary, background, glow, and contrast only.
- Light theme: orange-led on light surfaces.
- Dark theme: orange-led on charcoal/navy surfaces.
- Blue theme: blue-led accents.
- Green theme: green-led accents.
- Prefer SVG `currentColor`/props over duplicated files when practical.
